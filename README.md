Приложение для управления задачами.
Проект расположен по ссылке:

https://github.com/Tatiana-SPB/webdev-cw-instapro

Приложение- визуальный инструмент для управления задачами.

Функциональность:
возможность регистрации и авторизации;
возможность добавлять новые задачи с описанием, сроком и статусом исполнения;
возможность редактировать задачи в части описания, срока исполнения, категории и статуса.
